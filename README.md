# Joanakar Techno Engine — Android

Aplicación Android nativa con motor visual y conexión al feed público de YouTube.

## Funciones

- Configurar el identificador del canal desde la propia app, sin editar código.
- Leer los últimos vídeos públicos de YouTube sin clave API.
- Crear selecciones aleatorias sin canciones repetidas.
- Preparar una selección de hasta 15 vídeos para un set.
- Generar y guardar imágenes PNG de ondas futuristas.
- Abrir cada vídeo en YouTube.

## Crear el APK

1. Abre esta carpeta con Android Studio.
2. Espera a que termine la sincronización.
3. Pulsa **Build → Build APK(s)**.
4. El APK de prueba aparecerá en `app/build/outputs/apk/debug/app-debug.apk`.

La aplicación requiere Android 10 o posterior. El feed público de YouTube suele contener los últimos 15 vídeos; acceder al catálogo completo requiere la API oficial de YouTube.
